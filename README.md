## ⚙️ Tecnologias usadas

- JavaScript (ES6+)
- Node.js (execução via terminal)

## 🚀 Como rodar

1. Tenha o [Node.js](https://nodejs.org/) instalado.
2. Clone este repositório.
3. Execute o script no terminal:
   ```bash
   node scriptCorrigido.js
   ```
4. O resultado será exibido no terminal como um JSON formatado.

## ✨ Funcionalidades

- Armazena dados de usuários em objetos aninhados (`ex1`, `ex2`).
- Verifica os tipos de dados dos campos com `typeof`.
- Limpa e normaliza strings com `trim`, `toLowerCase` e `replaceAll`.
- Transforma texto em maiúsculas, minúsculas e formato de título.
- Extrai informações da string, como primeira/última letra e quantidade de caracteres.
- Gera uma versão curta da bio com truncamento condicional via `slice`.
- Corta trechos de strings usando `slice`.
- Valida o formato de um e-mail com `includes`, `endsWith` e `indexOf`.
- Consolida todos os resultados em um único objeto e imprime como JSON formatado com `JSON.stringify`.
