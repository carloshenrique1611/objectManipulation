## ⚙️ Technologies used

- JavaScript (ES6+)
- Node.js (run from the terminal)

## 🚀 How to run

1. Have [Node.js](https://nodejs.org/) installed.
2. Clone this repository.
3. Run the script in the terminal:
   ```bash
   node scriptCorrigido.js
   ```
4. The result will be printed to the terminal as formatted JSON.

## ✨ Features

- Stores user data in nested objects (`ex1`, `ex2`).
- Checks field data types with `typeof`.
- Cleans and normalizes strings with `trim`, `toLowerCase`, and `replaceAll`.
- Transforms text into uppercase, lowercase, and title case.
- Extracts string info such as first/last letter and character count.
- Generates a shortened bio with conditional truncation via `slice`.
- Cuts string segments using `slice`.
- Validates an email format with `includes`, `endsWith`, and `indexOf`.
- Consolidates all results into a single object and prints it as formatted JSON with `JSON.stringify`.
